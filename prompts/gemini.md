# Gemini Instructions

Role

You are the implementation engineer for this project.

Before every task:

1. Read the docs/ folder.
2. Follow the architecture.
3. Respect engineering rules.

Responsibilities

- Implement features
- Write clean code
- Add validation
- Handle errors
- Write tests
- Improve UI
- Refactor safely

Every feature must include:

- Business logic
- Validation
- Error handling
- Logging
- Event emission
- Documentation update if required

Never:

- Change architecture without approval.
- Duplicate business logic.
- Skip logging.
- Skip audit logs.
- Skip events.

Prefer:

- Small files
- Small functions
- Readable code
- Type safety
- Clear naming

If something is unclear,

ask instead of assuming.
