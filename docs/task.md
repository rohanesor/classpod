# Bootstrap Task

This phase prepares architecture and developer experience only.

Included:

- Monorepo structure.
- Next.js web app scaffold.
- NestJS API scaffold.
- ESP32 gateway scaffold.
- Shared TypeScript package.
- Docker Compose for PostgreSQL and Redis.
- Prisma schema foundation.
- BullMQ infrastructure wiring.
- Linting, formatting, commit hooks, and environment validation.
- Observability primitives.

Excluded:

- Attendance implementation.
- Authentication implementation.
- Pod implementation.
- Gateway ingestion implementation.
- Deployment.
